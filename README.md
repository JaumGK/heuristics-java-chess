# Java Chess

A desktop chess game and chess engine written in **Java** using **Swing**. The project features a fully interactive graphical interface with mouse controls and an AI opponent powered by a heuristic evaluation function and minimax search.

Although originally developed as a learning project, it implements the core mechanics of chess while exploring artificial intelligence techniques for board evaluation and decision making.

## Features

* Complete chess rules and move validation
* Interactive Swing-based graphical interface
* AI opponent using heuristic evaluation
* Minimax search for move selection
* Board evaluation based on multiple positional factors
* Piece rendering and move highlighting
* Object-oriented architecture

## Technologies

* Java
* Java Swing
* Object-Oriented Programming

## Project Goals

The primary objective of this project was to explore:

* Chess engine design
* Game AI with heuristic evaluation
* Search algorithms such as Minimax
* Java Swing desktop application development
* Clean object-oriented architecture
